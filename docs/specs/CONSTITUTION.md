# Escapement Constitution

1. Repository state outranks chat memory.
2. Specifications define behaviour before implementation.
3. Project-owned state is never overwritten by framework updates.
4. Deterministic evidence precedes model judgement.
5. Critical failures cannot be reported as passing.
6. Security-sensitive actions require explicit approval.
7. External resources require licence, security, and overlap review.
8. Privacy is local and minimal by default.
9. One bounded feature is verified before the next feature is promoted.
10. Every material session leaves a clean handoff.
