# Escapement v6.0.0

This release consolidates the former safety, evidence/evaluation, distribution,
and external-inspiration roadmaps into one package.

## Migration

1. Back up the repository.
2. Preview:

```bash
python scripts/escapement.py update /path/to/project
```

3. Resolve managed-file conflicts.
4. Apply:

```bash
python scripts/escapement.py update /path/to/project --apply
```

5. Run:

```bash
python scripts/escapement.py doctor --root /path/to/project
python scripts/escapement.py self-test
```

Project-owned state, specifications, feature lists, logs, and runtime history
are never overwritten by a normal update.
