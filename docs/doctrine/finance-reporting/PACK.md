# Finance, Data, and Reporting

Use for financial analysis, accounting logic, reconciliations, management
reporting, MIS, portfolio analysis, data pipelines, or KPI definitions.

## Metric contract

Every material number requires:

```text
Meaning
Formula
Unit
Period
Source
Freshness
Filters
Comparison
Owner
Drill-down
Reconciliation
Exception status
```

Show absolute values before ratios where management action depends on scale.

Use correct period logic:

```text
Current vs previous
Actual vs target
MTD / QTD / YTD
Financial year
Custom period
```

For financial processes, define journal, recognition, settlement, ageing,
reversal, and reconciliation logic only from approved rules.

Never invent totals, assumptions, XIRR inputs, accounting treatment, or source
data. Make rejected records and data-quality limitations visible.
