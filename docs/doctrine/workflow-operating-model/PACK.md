# Workflow and Operating Model

Use for business processes, approvals, lifecycle management, ownership,
exception handling, service levels, and recurring operating rhythms.

## Workflow contract

```text
Trigger
Actors
Input
Validation
State
Transition
Business rule
Control
System of record
Evidence
SLA
Exception
Escalation
Output
Closure
```

Separate:

- task management;
- workflow state;
- exception accountability;
- management oversight.

Define happy path, rejection, return, duplicate, timeout, reversal, cancellation,
reopening, and closure.

## Operating rhythm

Where relevant, specify:

```text
Daily operations
Weekly review
Monthly governance
Quarterly management review
```

Every exception needs a named owner, due date, ageing, status, evidence, and
escalation path.
