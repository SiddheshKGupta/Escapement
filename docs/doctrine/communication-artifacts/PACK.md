# Communication and Artifacts

Use for reports, emails, proposals, SOPs, presentations, spreadsheets,
management notes, and reusable written deliverables.

## Writing

- Lead with the point.
- Use plain, professional, positive language.
- Remove generic AI phrasing and repetitive structure.
- Distinguish fact, interpretation, recommendation, and action.
- Use headings and tables only where they improve navigation.
- Keep commentary proportional to the decision.

## Artifact logic

A document should be readable, a presentation should guide a discussion, and a
spreadsheet should support control and review.

For each artifact define:

```text
Audience
Decision or use
Source material
Structure
Formatting profile
Quality checks
Owner
Update frequency
```

Use the active profile for exact fonts, colours, page styles, totals, number
formats, and branding.
