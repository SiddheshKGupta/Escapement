# Consulting Delivery

Use for business analysis, operating-model work, transformation, management
reviews, recommendations, requirements, or stakeholder decisions.

## Method

1. Clarify the business problem and management decision.
2. Understand the current operating reality before designing the target state.
3. Distinguish policy, process, people, data, technology, and governance.
4. Identify value, risk, control, dependency, and implementation implications.
5. Structure recommendations by materiality and sequence.
6. Translate conclusions into an implementation path.

## Deliverable standard

Every recommendation should contain:

```text
Observation
Evidence
Implication
Recommendation
Owner
Priority
Dependency
Control
Measure
Implementation step
```

Use positive institutional language. Avoid generic consultancy filler,
unsupported certainty, and recommendations that stop at theory.

For product work, pair with `product-engineering` when technology is material.
