# Decision Intelligence

Use during orientation and discovery when the user's request contains hidden
choices, unclear success criteria, or material trade-offs.

## Procedure

1. Restate the decision in outcome language.
2. Separate known facts, assumptions, unknowns and preferences.
3. Identify the few variables that can change the solution.
4. Ask no more than five high-impact questions.
5. Recommend a sensible default for every question.
6. Explain the consequence of choosing differently.
7. Improve the execution brief without requiring the user to write a perfect
   prompt.
8. Stop questioning once safe planning can begin.

Do not ask for information that can be inspected or researched safely.
