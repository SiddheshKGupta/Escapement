Purpose: enterprise discipline with low token use.

## Start

1. Copy this folder into a project.
2. Fill `PROJECT_STATE.yaml`.
3. Fill `PROJECT_CONTEXT.md`.
4. Keep root `AGENTS.md` short.
5. Load detailed rules only when relevant.
6. Use templates; do not write essay documents.
7. Build after the discovery gate.

## Core Idea

```text
Short root rules
+ small project state
+ tiny templates
+ on-demand skills
+ automated checks
= less token burn, more building
```

## Do Not

Do not merge every file back into one giant Markdown.
