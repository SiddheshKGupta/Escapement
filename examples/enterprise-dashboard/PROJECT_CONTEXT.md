# Project Context

## Product
Enterprise management dashboard for operational and financial review.

## Users
Management, finance, operations, and authorised analysts.

## Outcome
Provide traceable KPIs with period comparison and record-level drill-down.

## Current Process
Management reports are compiled manually from multiple operational files.

## Constraints
- Financial year begins in April.
- Every KPI needs a source and reconciliation path.
- Access is role-based.
- Client branding is primary.

## Non-goals
- Replacing the source transaction systems.
- Automated financial posting.
