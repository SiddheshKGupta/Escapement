# Skill Governance

1. Define the capability need and expected output.
2. Compare native skill, doctrine pack, agent pattern, and external capability.
3. Check overlap groups and token cost.
4. Select the smallest effective option.
5. Evaluate with executable fixtures where possible.
6. Record marginal benefit, token overhead, failures, security, and maintenance.
7. Promote, revise, retain, demote, or retire based on repeated evidence.

One successful anecdote is not proof. More skills are not automatically better.
