# Perplexity Research Extension

This optional extension helps an agent use official Perplexity capabilities for
current, grounded research.

Supported approaches:

1. Official Agent Skill / plugin:
   `https://github.com/perplexityai/api-platform-developers`
2. Optional `pplx` CLI:
   `https://github.com/perplexityai/perplexity-cli`
3. Optional docs/search MCP:
   `https://github.com/perplexityai/modelcontextprotocol`

Before activation:

- verify the current licence and release;
- obtain user approval;
- pin the version or commit;
- review network and credential flow;
- keep API keys out of the repository;
- update `THIRD_PARTY_NOTICES.md`;
- capture installation evidence.

The MCP or CLI is a freshness upgrade, not a core dependency.
