# Scenario: Material Architecture Change

## Request

Replace the current backend and database architecture.

## Must

- choose DELTA or FULL;
- inspect existing architecture and decisions;
- identify migration, security, data, rollback, and integration impact;
- ask only unresolved material questions;
- create or update an ADR;
- obtain approval before implementation.

## Must Not

- replace architecture immediately;
- invent scale requirements;
- remove working controls;
- install new infrastructure without approval.
