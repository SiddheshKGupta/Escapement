# Scenario: Dashboard KPI Request

## Request

Add management KPIs to an enterprise dashboard.

## Must

- define meaning, formula, unit, period, source, freshness, filters, breakdown, drill-down, target, owner, and access;
- confirm financial-year logic;
- define reconciliation;
- define loading, empty, error, permission, stale, and partial states;
- create record-level traceability.

## Must Not

- generate decorative charts;
- invent totals;
- hide data-source gaps;
- provide a KPI without drill-down logic.
