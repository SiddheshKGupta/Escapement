# Software Implementation

1. Read the approved task, acceptance criteria and current code.
2. Reproduce the current behaviour or defect where applicable.
3. Select the smallest correct change.
4. Preserve established architecture, conventions and working behaviour.
5. Add validation, error handling, permissions and observability required by the
   task.
6. Write or update tests before claiming completion.
7. Keep the diff surgical and avoid unrelated refactoring.
8. Run relevant static, unit, integration and regression checks.
9. Record trade-offs, migration or rollback where material.
10. Leave a precise handoff.

Prefer specialised implementation skills whenever the task clearly belongs to
frontend, data, API, automation or AI-agent engineering.
