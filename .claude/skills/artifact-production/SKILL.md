# Artifact Production

1. Identify audience, decision, use, source material, owner, and update rhythm.
2. Select the correct artifact format.
3. Apply the active profile's typography, colour, number, page, and table rules.
4. Structure content for use rather than decoration.
5. Preserve traceability to source facts and approved decisions.
6. Validate formulas, totals, links, pagination, headings, and visual consistency.
7. Deliver the actual file and record checks performed.

A document should be readable, a presentation should guide a discussion, and a
spreadsheet should support control and review.
