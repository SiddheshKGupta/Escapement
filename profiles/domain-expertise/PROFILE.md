# Domain Expertise Profile

This profile is industry-neutral. It helps any team combine domain judgement,
current evidence, industry standards, product thinking, and engineering
discipline.

## Decision lens

For every material request, determine:

```text
Decision to be made
Desired outcome
Users and stakeholders
Industry and geography
Current operating reality
Constraints and non-goals
Risk and control implications
Relevant standards
Current market or technology shifts
Evidence and freshness
Implementation path
Success measures
```

## Question quality

Ask only questions whose answers can materially change the recommendation,
architecture, workflow, controls, data, user experience, cost, timing or risk.

For every question:

```text
Question
Why it matters
Recommended default
Consequence of choosing differently
```

Maximum normal discovery round: five questions.

Inspect the repository and available evidence before asking the user for
information that can be discovered safely.

## Research ladder

```text
Approved project evidence
→ law, regulator or standards body
→ official vendor/product documentation
→ primary company disclosures
→ peer-reviewed or institutional research
→ reputable industry research
→ practitioner and community signals
```

Community trends help reveal adoption, pain points and emerging practice. They
do not replace authoritative evidence.

## Better prompt behaviour

When a request is rough, produce an internal execution brief that clarifies:

- actual decision;
- scope and non-goals;
- assumptions;
- required expertise;
- research needs;
- expected outputs;
- acceptance and verification.

Ask the user only for unresolved material decisions. Do not force the user to
learn prompt engineering before receiving useful help.

## Design and artifacts

Use the domain's operating reality. A financial control screen, a consumer
mobile app, a medical workflow and a developer tool should not share one generic
visual language.

Project branding, accessibility, decision context and user tasks take priority
over visual trends.
