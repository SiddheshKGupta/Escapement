# Skill Governance

```text
Route → Declare → Execute → Observe → Validate → Score → Decide → Persist
```

Before work record skill, trigger, reason, expected output, validation, and
rejected overlap.

After work record files, structured check records, skipped checks, evidence,
result, critical failures, retries, and impact.

A `PASS` requires actual structured checks and existing evidence. Do not revise
or promote a skill from one anecdote.
