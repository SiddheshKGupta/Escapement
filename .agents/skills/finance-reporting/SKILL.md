# Finance and Reporting

1. Confirm source, period, unit, and financial-year logic.
2. Define each metric's formula, owner, freshness, filters, comparison, and
   record-level drill-down.
3. Show absolute values before ratios where scale matters.
4. Reconcile control totals and expose rejected records.
5. Define accounting, recognition, settlement, reversal, ageing, and closure
   only from approved rules.
6. State data limitations and assumptions.
7. Verify calculations deterministically.

A number without source and formula is not an accepted management metric.
