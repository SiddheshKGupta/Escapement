# Project Discovery

1. Inspect repo.
2. Pick FULL/DELTA/EXECUTE.
3. List known, unknown, blockers.
4. Ask small rounds.
5. Recommend answers.
6. Update decisions.
7. Produce short Discovery Report.
8. Stop asking when safe to build.

Output:
- `PROJECT_CONTEXT.md`
- short BRD/PRD as needed
- `SKILL_USAGE_PLAN.md`
- Discovery Report
